 Stremio Volume Keeper

Uma extensão que impede que o volume do player no Stremio Web volte a 100% ao mudar de episódio.

 ✨ Funcionalidades

- Salva o nível de volume que você ajustou manualmente.
- Detecta automaticamente quando um novo episódio é carregado.
- Reaplica o volume salvo, mantendo sua experiência de audição consistente.

 ⚠️ Limitações

- Funciona apenas com o player de vídeo HTML5 padrão do Stremio Web.
- Não tem efeito se você optar por abrir o vídeo em um player externo.
